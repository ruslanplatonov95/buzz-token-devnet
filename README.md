# BUZZT — только тест в Solana Devnet

Этот каталог содержит воспроизводимый сценарий выпуска тестового токена. Это не токен для продажи, инвестиций, пожертвований или использования с реальными деньгами. Devnet может быть сброшен, а тестовые единицы не имеют денежной стоимости.

## Что делает сценарий

`issue.mjs` создаёт mint Token-2022 с именем `BUZZ DEVNET TEST` и символом `BUZZT`, выпускает 10 000 000 целых тестовых единиц на тестовый кошелёк, отзывает право дополнительной эмиссии и сжигает одну единицу в демонстрационной транзакции. После успешного запуска он сверяет предложение, остаток и метаданные с блокчейном. Повторный запуск использует те же тестовые ключи и не должен выпускать новую партию.

Комиссия с переводов и автоматическое сжигание не включены: для них нужны отдельные правила, экономическая модель и тесты. Никаких прав на доходность, ценовой «пол», погашение или airdrop за деньги этот токен не даёт.

## Перед запуском

1. Установить зависимости из `package.json` командой `pnpm install`.
2. Пополнить публичный адрес тестового плательщика бесплатным **Devnet SOL** из [официального faucet](https://faucet.solana.com/). Никогда не отправлять на него настоящий SOL из mainnet.
3. Запустить `node issue.mjs` и сохранить напечатанный адрес mint и подписи транзакций.
4. Проверить адрес mint в [Solana Explorer](https://explorer.solana.com/?cluster=devnet), выбрав сеть Devnet.

Файлы `.test-authority.json` и `.mint-keypair.json` содержат **только тестовые** закрытые ключи, исключены из Git и не подходят для mainnet. Не публиковать их и не использовать этот каталог как хранилище реальных средств.

Статус: сценарий подготовлен, но выпуск в Devnet пока не подтверждён. Для запуска требуется бесплатный Devnet SOL на тестовом адресе. Публикация этого репозитория не означает, что токен уже выпущен.
